# Configuration and Settings

CalendarApi comes with a lightweight `toml` config loader and parser for advanced usage.

The HTTP options (`HTTPClientConfig`) can also be passed to `CalendarApi` / `AsyncCalendarApi` as keyword arguments (`HTTPClientOptions`), see the [Configuration](../index.md#configuration) section.
